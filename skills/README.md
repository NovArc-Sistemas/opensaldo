# Skills

Ainda vazia. As skills entram aqui, uma pasta por skill (`skills/<nome>/SKILL.md`), conforme saírem do painel que já roda em produção:

| Skill planejada | O que faz |
|---|---|
| `opensaldo-painel` | Gera e publica o painel cifrado como Artifact a partir dos seus dados. |
| `opensaldo-importar` | Lê extrato, fatura ou print e lança no painel. |
| `opensaldo-categorizar` | Revisa a fila de lançamentos sem categoria e cria regras. |
| `opensaldo-atualizar` | Rotina diária: busca os bancos, recalcula e republica. |

Nenhuma delas está publicada. Acompanhe pelo [README](../README.md).
